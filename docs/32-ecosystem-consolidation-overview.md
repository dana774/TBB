# 32 — Ecosystem Consolidation Executive Overview (INTERNAL)

**Internal strategy — not for the public site.** Captured from *Brand Blueprint / VGP Ecosystem
Consolidation Executive Two-Pager v2.0*. This is operating strategy (portfolio consolidation +
website migration plan), which per doc 25's rubric stays internal. The **public-safe essence** —
"two front doors" — already matches the live site architecture and the `/ecosystem` page.

## Operating thesis
**Consolidate backstage. Differentiate frontstage.** One canonical source produces multiple approved
resources, learning products, media assets, proof points, and website pages. Don't reduce founder
value or merge the brands — consolidate the work behind the scenes and present two clear front doors.

## The two front doors (public-safe)
- **The Brand Blueprint** — founder-facing: signals, tools, membership, relationships, opportunity
  flow. Nav: Founders | Resources | Signals | Ecosystem | About. CTA: *Choose Your Path / Join
  Founder Network*.
- **Value Growth Partners** — advisory: diagnostics, advisory, Growth OS implementation, programs,
  speaking, fractional support. Nav: Capabilities | Growth OS | Programs | Speaking | Insights |
  About. CTA: *Start a Diagnostic*.
- **Brand rule:** Brand Blueprint leads ecosystem-facing pages; VGP leads advisory, implementation,
  programs, proposals, and institutional pages. **Growth OS is a VGP offer, not a third company.**

## The 6 operating portfolios (from 10 project segments)
1. **Founder Network + Resource Experience** — membership, resource library, onboarding, alumni continuity
2. **Signal, Media + Opportunity Engine** — podcast, Market Signal, Funding Friday, Hot List, events
3. **Readiness + Market Access Platform** — capital, retail, distribution, sourcing, operating readiness
4. **VGP Advisory + Growth OS Delivery** — diagnostics, sprints, dashboards, automation, managed/fractional
5. **Institutional Programs + Learning Products** — curriculum, workshops, mentorship, office hours, speaking
6. **Partner, Investor + Expert Ecosystem** — investor pipeline, referral partners, specialists, sponsors

## Duplication to eliminate
- One Capital + Opportunity Engine (not separate funding scans/trackers/readiness/pipeline projects).
- One Retail + Channel Readiness track (not separate buyer/ECRM/spec-sheet/promo/distribution/pilot).
- One **public** Growth OS architecture; VGP agents, prompts, Google systems, automation stay internal.
- One learning-product package for every seminar, workshop, cohort module, founder resource.
- One relationship system for investors, referral partners, specialists, sponsors, institutions.
- **One public engagement ladder** — do not publish legacy founder tiers and Growth OS packages at once.

## Critical website changes (internal build backlog)
- Replace generic contact / calendar-first behavior with an **audience router + route-specific forms**.
- Remove the VGP public calendar catalog; expose approved Calendly routes only after fit/context.
- Deduplicate ~50 VGP + ~35 Brand Blueprint blog posts; podcast → Brand Blueprint, capability/case → VGP.
- Convert legacy capsule pages into structured founder stories / Resource Library previews; fix copy-of slugs with redirects.
- Resolve VGP phone/social inconsistencies, validate legacy form storage, preserve Brand Blueprint form data.

## 30 / 60 / 90 sequence
- **1–30:** approve the six portfolios, source registers, platform, membership, offer names, public pricing, forms, Calendly, proof/trust details.
- **31–60:** bundle Retail, Capital, Growth OS, Founder Network "Start Here," and Partner systems; create website content + redirect manifests.
- **61–90:** build Brand Blueprint staging first, then VGP; migrate canonical content, QA, cut over one site at a time with rollback plans.
