## The five operating layers (from the Growth OS manual)
The public `/ecosystem` page uses the **simplified 3-layer** brand model (Brand Blueprint → VGP → Growth OS) because it's cleanest for visitors. The manual's fuller **5-layer** operating model is: **Signal Engine** (media + intelligence) → **Founder Network** (membership + community) → **VGP Advisory** (strategy + execution) → **Growth OS** (systems + automation) → **Apex** (fractional leadership). We can expose the 5-layer version on a deeper page if you want the full ascension shown.

## Rubric for any NEW ecosystem doc you send
1. **Is it client-facing or internal?** Internal operating manuals, automation/agent playbooks, pricing *governance*, and partner *economics* stay internal (not on the public site).
2. **Which audience?** → Founders = home / capabilities / membership; Institutions = programs; Investors & referral partners = `/investors-partners`; everyone = `/ecosystem`.
3. **What's the artifact type?** Methodology/process → a capability or How-We-Work section; pricing tier → membership / how-we-work; a one-pager → the matching audience page.
4. **Guardrails:** no guaranteed-results language; no unverified numbers; keep partner/pricing economics internal unless approved for publication.
